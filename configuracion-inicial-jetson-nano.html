Configuración Inicial Jetson Nano

Introducción:

El componente especializado en Inteligencia Artificial de nuestra arquitectura es la Nvidia Jetson Orin Nano. Este dispositivo representa el estado del arte en computación en el borde (Edge Computing), integrando la arquitectura GPU Nvidia Ampere en un formato embebido de bajo consumo. Su inclusión en el clúster tiene como objetivo principal la descarga de tareas de paralelización masiva, específicamente aquellas relacionadas con la inferencia de redes neuronales profundas (Deep Learning) y visión por computador. A través de este nodo, el sistema adquiere capacidad de procesamiento tensorial nativo, utilizando el ecosistema de librerías CUDA y TensorRT para ejecutar modelos complejos con una latencia mínima, sin depender de servicios en la nube.

Unboxing:

Vamos a necesitar un cable con enchufe europeo ya que con la jetson nano solamente vienen cables de Reino unido y de Estados unidos.

Conectamos el display port a nuestro monitor

Configuración Inicial:

Al instalar la micro sd proporcionada por el profesor, podemos observar el panel de instalación de ubuntu, sin embargo lo primero que aparece son las licencias de NVIDIA ya que este SO viene preparado y optimizado para usar en las jetson.

Seleccionamos el idioma del sistema

Establecemos el usuario, la contraseña y el nombre del equipo

Seleccionamos que instale chromium web browser

Instala chromium y los paquetes necesarios para instalar las aplicaciones como snap

Al finalizar la instalación este es el escritorio que viene con las herramientas de nvidia preinstalada

Por ultimo, instalamos las actualizaciones del sistema

Ollama:

En primer lugar instalamos ollama con el script de instalación que aparece en su página web

En segundo lugar usamos ollama para lanzar el modelo ministral de 3 billones de parametros, ollama detecta que no lo tenemos en local y comienza a descargarlo.

Posteriormente, al finalizar la descarga, lanza un error indicando que no puede cargar el modelo ya que no hay espacio suficiente, limpiamos la cache. Sin embargo posteriormente comprobamos que ese modelo en concreto aun siendo pequeño ocupaba más memoria de la que disponemos.

Con esto concluiríamos con la instalación de ollama.

Jtop

Para monitorear los recursos que utilizamos, vamos a utilizar la herramienta jtop, que es un monitor de recursos derivado de TOP de linux, sin embargo esta herramienta esta hecha para que funcione con las jetsons.

Para llevar a cabo las pruebas de rendimiento correremos el modelo qwen2.5 de 3 billones de parametros y le pediremos que nos cuente un cuento para tener suficiente tiempo para obserbar los consumos, temperaturas y % de uso de la gpu.

Podemos observar que el uso de la gpu es de casi el 100%, la temperatura ha ascendido de 47º a 53.3º y el consumo eléctrico ha subido de 5.3W a 16W.
